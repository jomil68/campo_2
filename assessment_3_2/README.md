# Assessment 3.2: Linear Data Structure

**Author:** Jomil Campo

Dynamic programs based on the algorithms from Assessment 3.1. Each program asks
for a name, adds every letter, then removes them one by one until the structure
is empty, printing the state after every step.

| File | Structure | Add | Remove |
|------|-----------|-----|--------|
| `array_program.py` | Array | Index 0 to n-1 | From last index |
| `stack_program.py` | Stack (LIFO) | Push | Pop |
| `queue_program.py` | Queue (FIFO) | Enqueue (rear) | Dequeue (front) |
| `linked_list_program.py` | Singly Linked List | Insert at tail | Delete head |

## How to run
```
python array_program.py
python stack_program.py
python queue_program.py
python linked_list_program.py
```
Type `CAMPO` (or any name) when prompted, or `q` to quit.
